모델

분류 기준
  기본은 원본 데이터의 라벨(AI-Hub 품목 코드 등)이고, 사용자가 사진을 보고 내린 검수 결정이 있으면 그것이 우선합니다.
  CAN    음료캔 등 금속 캔. 이물질 표시가 있는 캔(AI-Hub c_3_01)도 CAN.
  PET    PET 병 + 단단한 플라스틱 용기 (2026-10-16 사용자 결정: PET와 플라스틱을 한 클래스로). 갈색·유색 PET 포함.
         - 라벨: A는 라벨이 붙은 PET·플라스틱을 OTHER로, B는 PET로 둡니다.
           몸체에 직접 인쇄된 것은 라벨이 아님(A·B 모두 PET). 붙인 인쇄 필름(뚜껑 필름, 수축 필름)은 라벨로 봅니다.
         - 이물질 코드는 4클래스 라벨에 쓰지 않습니다 (2026-10-24 사용자 결정, beta-2에서 새로 적용).
           페트+이물질(c_5_02_01)은 A·B 모두 PET, 페트+이물질+다중포장재(c_5_01_01)는 B는 PET, A는 라벨 붙은 것으로 보고 OTHER.
           오염 판별은 나중에 별도 모델로 할 예정입니다.
         - 플라스틱도 원본에 이물질 표시가 있어도 사진에서 깨끗해 보이면 PET (2026-10-17, 10-22 사용자 결정).
  GLASS  유리병(갈색·녹색·백색, 소주·맥주 재사용병)과 기타 유리.
         "글라스 밀폐용기" 스티커가 붙은 유리 용기는 원본이 플라스틱이어도 GLASS (2026-10-22 사용자 결정).
         흰 도자기 머그는 GLASS가 아닙니다 (일부는 학습에서 뺐고, 일부는 OTHER로 남아 있음).
  OTHER  위 셋이 아닌 것: 종이, 종이팩, 종이컵, 비닐, 스티로폼, 건전지, 필름·봉투 같은 무른 플라스틱,
         그리고 A 변형의 라벨 붙은 PET·플라스틱.
  추가 규칙: 1등이 GLASS여도 GLASS 확률이 임계값보다 낮으면 OTHER (아래 전처리 5번).

INT8 양자화 (2026-10-25)
  파일: beta-2a-esp32s3-int8.espdl, beta-2b-esp32s3-int8.espdl (각 약 2.5 MB, 전부 INT8, 16비트 층 없음)
  도구: esp-ppq 1.3.11, target esp32s3, w8a8, ESP-DL S3 INT8 형식으로 내보냄.
        S3 규칙대로 층마다 눈금 하나(per-tensor), 눈금은 2의 거듭제곱, 0점 없음(대칭). bias는 20비트.
  절차:
    1. 사후 양자화(PTQ): 학습 세트의 AI-Hub 실내형 사진 512장(클래스당 128장, 40 % 구도)을 통과시켜
       활성값 눈금(KL 방식)과 가중치 눈금(최댓값 방식)을 정함. S3 연산 조건(출력 눈금 >= 입력 눈금 x 가중치 눈금) 보정.
    2. 입력 눈금 보정: 정규화된 입력 범위(-2.12 ~ 2.64)가 잘리지 않도록 입력 눈금을 2^-5로 다시 잡음.
       (1번만 하면 2^-6으로 잡혀 입력값의 약 10.8 %가 잘렸고, 정확도가 크게 떨어졌습니다.)
    3. TQT(학습형 눈금 조정): 모델을 2개 층씩 묶어, 묶음마다 FP32 출력과 INT8 출력의 차이가 줄도록
       눈금(2의 거듭제곱 지수)과 가중치를 조금씩 조정. 정답 라벨은 쓰지 않음.
       500단계, 학습률 5e-5, 사진 1,024장(클래스당 256장, 1번 사진 포함). 묶음 결과가 나빠지면 되돌림.
    - 사진은 모두 학습 세트에서만 뽑았고, calibration·test·B9 평가 사진과 겹치지 않습니다.
    - 학습(QAT)을 다시 한 것은 아닙니다. 위 과정은 몇 분 걸리는 변환 단계입니다.
