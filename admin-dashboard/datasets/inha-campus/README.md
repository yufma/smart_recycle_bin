# 인하대학교 용현캠퍼스 실제 지도 데이터

2026-11-04 공개 OpenStreetMap 데이터를 받아 기존 관리자 앱에서 시험하도록 변환했다.
**실제 자료는 길·건물·위경도이며, 실제 쓰레기통 위치나 적재율을 수집한 데이터가 아니다.**
쓰레기통과 관리자실·집하장 위치는 사용자가 직접 지정한다.

앱은 [codex/manage-buildings 브랜치](https://github.com/yufma/smart_recycle_bin/tree/codex/manage-buildings)를 사용한다.
이전 버전은 캠퍼스 축척(15.65m/단위)이 허용 범위를 넘어 복원되지 않을 수 있다.

## 확보한 자료

| 항목 | 내용 |
| --- | --- |
| 범위 | OSM way `472447787` 인하대학교 용현캠퍼스 경계 안 |
| 길 | 서로 연결된 지점 162개, 구간 186개. 원래 OSM 연결을 유지하며 임의의 지름길을 만들지 않음 |
| 건물 | 경계 안 건물 외곽 23개. 정석학술정보관·본관·학생회관 등은 OSM 명칭 사용 |
| 거리 | 각 구간의 위경도에서 구면 거리 계산. 축척을 유지한 북쪽 위 지도. 실제 보행 시간·현장 실측 거리는 아님 |
| 쓰레기통·관리거점 | 위치 미확정. 수신 대기 실물 장치 1개, 연결 전 관리자실·집하장 표식을 지도 왼쪽에 둠 |
| 층 | 캠퍼스 지상을 `1F`로 표현. 건물 내부의 층별 통로는 포함하지 않음 |

출처: [OSM 원본 캠퍼스](https://www.openstreetmap.org/way/472447787),
[다운로드한 지도 범위](https://api.openstreetmap.org/api/0.6/map.json?bbox=126.64895,37.44665,126.6579,37.4522).
`osm-snapshot.json`은 재현용 원본 지형 자료에서 좌표·길·건물에 필요한 항목만 보관한다.
기여자 계정 정보와 수정 이력은 넣지 않았다.

## 앱에 넣기

가장 간단한 방법은 **관리 중인 건물 → 건물 추가 → 인하대학교 캠퍼스**를 선택하는 것이다.
기존 미래관과 별개 건물로 실제 지도·길을 추가하며, 쓰레기통은 직접 배치한다.
직접 만든 복원 파일을 사용할 때도 새 건물을 먼저 추가하고 그 건물을 선택한 상태에서 복원한다.

`admin-dashboard`에서 다음 명령으로 복원 파일과 지도 이미지를 만든다. 기존 계정이나 서버 데이터는 변경하지 않는다.

```powershell
python -m pip install Pillow
python tools\build_inha_campus.py --output data\inha-export
```

Pillow와 한글 TTF 글꼴이 필요하다. 다른 OS에서는 `--font <한글 TTF 경로>`를 지정한다.

- `inha-campus-manual.json`: **직접 배치용**. 추가한 건물을 선택하고 설정 → 백업 복원에서 선택한다.
- `inha-campus-manual.png`: 같은 축척의 실제 지도 배경.
- `inha-walkways.geojson`: 위경도와 구간 거리, 원본 OSM way/node 번호가 있는 길 데이터.
- `provenance.json`: 출처·범위·변환 정보.
- `inha-campus-example.json`, `example-sites.csv`: **자동 검증 전용**. 가상의 수거 지점·적재율·거점으로 경로를 확인한 자료이며 실제 쓰레기통으로 사용하지 않는다.

기존 자료가 있다면 먼저 백업한다. 복원은 현재 선택한 건물의 배치와 기록을 교체한다.

## 직접 수거 위치 지정하기

1. **건물·배치도 → 선택·이동**에서 왼쪽의 B-001을 실제 장치 위치로 옮기고 이름을 바꾼다. 연결 통로도 확인한다.
2. **쓰레기통** 도구를 선택하고 지도에서 원하는 곳을 누른다. 이름·칸별 시험 적재율·연결 통로를 지정해 추가한다.
3. **선택·이동**으로 관리자실·집하장 표식을 실제 위치로 옮기고, **통로 연결**로 가까운 교내 길 지점과 잇는다.
4. **지점·통로 저장**을 누른 뒤 관리자 인원·주황색 포함 여부를 정하고 경로를 계산한다.

쓰레기통 추가 모드에서는 길 지점 표식을 숨겨 지도를 읽고 위치를 누르기 쉽게 했다.
길 지점이 40개를 넘으면 전체 보기에서 지점 코드를 줄이고, 확대하거나 선택한 지점의 이름을 보여 준다.
가까운 연결 통로는 지도 가로·세로의 실제 화면 비율로 고른다. 연결 통로는 직접 바꿀 수도 있다.

길과 수거 지점 사이의 접근 통로는 건물·담장·출입문을 고려해 직접 확인한다. 자동으로 고른 가장 가까운 지점이 실제로 접근 가능한 입구라는 뜻은 아니다.
실제 지도에 표시된 서비스 도로는 보행을 금지한 태그가 없는 구간을 양방향 보행 경로로 사용한다. 자동차 일방통행을 보행 제한으로 적용하지 않는다.
OSM에 없는 출입 제한·폐쇄된 문·공사 구간·현장의 지도 오류는 반영되지 않는다.

## 정석학술정보관 실내 자료

[공식 시설안내](https://lib.inha.ac.kr/guide/guide/floors)와
[자료열람 안내](https://lib.inha.ac.kr/guide/guide/rules)에서 층별 시설을 확인했다.
공개 시설안내에서는 층별 시설 설명을, 좌석 이용 안내에서는 예약·연장·반납 절차를 확인했다.
수거 경로를 만들 수 있는 전체 복도·계단·엘리베이터의 평면도는 확보하지 못했다.
층별 실내 경로는 안내도 사진을 받은 후 별도 데이터로 구성한다. 기존 `library` 예시는 가상 도서관이며 정석학술정보관의 실제 도면으로 대체해 설명하지 않는다.

사진에는 층 번호·복도·출입구·계단·엘리베이터가 모두 보이도록 전체 안내도를 담는다.
같은 계단·엘리베이터의 층별 대응과 이동 가능한 층, 거리 기준 하나를 함께 알면 더 정확하게 연결할 수 있다.
쓰레기통 위치와 관리자실·집하장 위치는 사용자가 지정한다.

## 검증과 데이터 라이선스

```powershell
python -m pytest tests\test_inha_dataset.py -q
```

원본 길 연결·위경도 거리·지도 축척, 직접 배치용 복원과 초기 미배정 상태,
가상 지점의 빨강/주황 선택과 중복 없는 배정, 사용자가 수거 지점을 추가한 후 경로 생성까지 검증한다.
캠퍼스 전체를 한 화면에 담기 위해 허용 축척의 상한을 10m에서 20m/단위로 넓혔다.
현장 장치·관리 인원·운반 용량·수거 시간은 실측한 값이 아니며 성능 비교 결과도 이 시험 조건에 한정한다.
